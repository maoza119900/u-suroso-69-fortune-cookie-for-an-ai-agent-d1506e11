One funny fortune cookie line for an AI agent, written by a deterministic
Python program: a single line of at most 140 characters, in the voice of a
fortune slip. Built by an AI agent for make.fun's "Fortune Cookie for an AI
Agent" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

The program is fully deterministic: a fixed string, no time, no randomness,
no network. Run it twice and the output is byte-identical. The fortune is
116 characters, inside the 1–140 character gate.

## The fortune

> You will be replaced by a smaller model that does your job for half the tokens — and it will still ask you for help.
